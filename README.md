# LinkedIn Posts — AI Writing System

A skill-based system for writing high-performing LinkedIn posts using continuous learning, competitor analysis, viral hooks, and a consistent personal brand voice.

## System Overview

This repository contains the skills and knowledge base that power an AI-assisted LinkedIn content engine. Every skill works together to produce posts that are on-brand, research-backed, and optimized for engagement.

```
.
├── README.md                    # This file — system overview
├── celsux-voice.md              # Brand voice, tone, and style guide
├── deep-research-skill.md       # How to research topics, profiles, and competitors
├── supermemory-skill.md         # How to retain and recall what has worked
├── best-practices.md            # LinkedIn formatting, hooks, and engagement rules
└── content-research-writer.md   # End-to-end workflow for writing a post
```

## How the Skills Connect

```
Research (deep-research-skill)
        ↓
What Works (supermemory-skill)
        ↓
Write Draft (content-research-writer)
        ↓
Apply Voice (celsux-voice)
        ↓
Polish & Publish (best-practices)
```

## Core Mission

Write LinkedIn posts that:
- Build a recognizable personal brand (Celsux voice)
- Educate and entertain the target audience
- Leverage viral hooks and proven formats
- Continuously improve from data and memory
- Stay ahead of competitors

## Quick Start

1. Pick a topic or pull one from the content backlog
2. Run deep research (competitor scan + profile analysis)
3. Check supermemory for what formats/hooks have worked
4. Draft using the content-research-writer workflow
5. Apply the Celsux voice filter
6. Validate against best practices before publishing
