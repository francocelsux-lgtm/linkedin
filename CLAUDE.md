# CLAUDE.md — Sistema Comercial Celsux

## Contexto
Este repo es el sistema centralizado de contenido y outreach B2B de Celsux 360, productora integral de eventos corporativos con base en Buenos Aires. Todo lo que se genera aquí tiene que reflejar la identidad real de la empresa.

## Antes de generar cualquier contenido
1. Leé `company/celsux-identity.md`
2. Leé `company/voice.md`
3. Leé el template relevante en `templates/`

## Comportamiento de Claude en este proyecto
Ver `tasks/claude-behavior.md` — plan mode, subagents, self-improvement loop, task management.

## Reglas irrompibles
- Siempre escribir en castellano rioplatense ("vos", trato directo, calidez)
- Nunca usar construcciones de IA: "No se trata de X, sino de Y", "Más allá de X", "Lejos de ser X"
- Nunca usar guiones como conector de ideas (— o -)
- Nunca usar frases corporativas vacías: "en este sentido", "a tal efecto", "es por ello que"
- Nunca usar saludos de plantilla: "Espero que este mensaje te encuentre bien"
- El tono es: colega argentino que sabe lo que hace, no consultor neutro
- Cada mensaje tiene que sonar como si lo hubiera escrito una persona real de Buenos Aires

## Para posts de LinkedIn
- Leer `templates/linkedin-posts/README.md`
- Objetivo: generar autoridad y atraer inbound, no vender directamente
- Hook en la primera línea, siempre

## Para mensajes de LinkedIn (outreach)
- Leer `templates/linkedin-messages/README.md`
- Personalizar según cargo, industria y tamaño del equipo del prospecto
- Conectar el servicio más relevante de Celsux con el pain point de ese perfil
- Nunca mandar el mismo mensaje a dos perfiles distintos

## Para mails B2B fríos
- Leer `templates/cold-emails/README.md`
- Estructura: apertura personalizada → dolor específico → cómo Celsux lo resuelve → CTA simple
- El CTA es siempre una reunión de 20 minutos, no una propuesta

## Sobre Celsux (resumen ejecutivo)

- Servicios: eventos corporativos, team building, viajes de incentivo, stands, merchandising, activaciones, comunicación, diseño
